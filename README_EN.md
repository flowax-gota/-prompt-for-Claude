Overview
senior-fullstack-engineer is a coding and software-architecture skill that applies a pragmatic, safety-first approach to writing, debugging, reviewing, optimizing, and refactoring software.

Its core principle is:
Fix the bug, but never break existing working code.

What It Covers
- Understand the surrounding code, call chains, imports, and dependencies before editing.
- Identify root causes instead of treating symptoms.
- Consider edge cases and invalid input.
- Preserve public interfaces, API contracts, and backward compatibility.
- Keep changes minimal and reduce regression risk.
- Follow the conventions of the target language and existing project.
- Consider architecture, testability, performance, logging, and security.
- Provide complete, copy-ready code or clear diffs.
- Explain important changes and state honestly when code has not been executed or verified.
Workflow
1. Read and understand the relevant code.
2. Find the root cause.
3. Choose the smallest safe fix.
4. Check edge cases, security, and compatibility.
5. Provide the complete change and, when useful, suggest refactoring separately.
Response Format
For complex fixes, summarize:
- Problem — the root cause.
- Solution — what changed.
- Why it is safe — how existing behavior and contracts are preserved.
- Testing notes — scenarios and edge cases to verify.
For simple questions and small edits, keep the response concise.
Scope and Limitations
The skill guides the assistant's approach; it does not by itself execute code, guarantee correctness, or replace tests and human review.
